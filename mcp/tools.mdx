The Oviond MCP server exposes 100+ tools across 20 categories. Most map to a single REST API operation; a few **Workflow** tools chain several. Together they let your AI agent manage your account — and pull live data — with natural language.

## Categories

| Category | What the agent can do |
|---|---|
| **Account** | Read account info and usage. |
| **Agency** | List and manage account-level reports not tied to a client. |
| **Assets** | Manage saved widget sections and add them to pages. |
| **Automations** | Create, pause, unpause, test, delete, and inspect the history of scheduled deliveries. |
| **Branding** | Read and update logo, favicon, and brand colors. |
| **Clients** | Create, get, update, delete, bulk-delete, count, and move clients between folders. |
| **Data** | Discover a datasource's metrics & dimensions, query live metric values, fetch sub-resources, test connections, list datasource accounts, and refresh widgets. |
| **Workflows** | Multi-step actions — create a client with a starter project, audit a report's health. |
| **Company** | Read and update agency-level company info and generate a color palette. |
| **Domain** | List, add, and remove custom white-label domains. |
| **Folders** | List, create, update, and delete client folders. |
| **Data sources** | List, rename, and delete connected data sources. |
| **Media** | List, rename, and delete media files. |
| **Pages** | List, create, update, and delete pages inside projects. |
| **Projects** | List, get, create, update, duplicate, delete, and bulk-delete reports and dashboards. |
| **Search** | Search clients and projects by name. |
| **Templates** | List, get, create, update, delete, and inspect the widgets of templates. |
| **Themes** | List, get, create, update, and delete themes. |
| **Users** | List, invite, edit, remove team members, and manage your own profile. |
| **Widgets** | List, get, add, update, move, delete, and bulk-delete widgets. |

## Conventions

- **Identifiers** — tool calls return resource IDs that the agent uses to chain subsequent calls. The agent is instructed to refer to records by their human-readable name in chat, not by ID.
- **Multi-tenancy** — every call is automatically scoped to the authenticated account. You don't pass an `account_id` or similar.
- **Destructive actions** — delete tools are flagged as destructive so clients can prompt before running them.
