title: "Goals"

A **goal** is a target you set for a metric — for example *Q4 revenue ≥ $250,000* or *cost per lead ≤ $40*. A goal ties a target value to a metric query, so you can show clients how actual performance compares to the target.

Goals are managed inside the report editor, on the **Goals** tab.

## How a goal is defined

- **Data** — a metric from a connected data source (the same builder used for widgets and calculated metrics).
- **Target** — the number to reach.
- **Type** — **Fixed value** compares the metric with the target as it is; **% change vs previous** compares the change against the previous period.
- **Comparison** — **At least (≥)**, **Exactly (=)** or **At most (≤)** the target.
- **Format** — Numeric, Decimal, Percentage or Currency.

## Use a goal

Add a **Goal** widget from **Add Content** and pick the goal. It shows a gauge with progress towards the target.

## Find goals

On the **Goals** tab:

- **Search goals...** — search by name.
- **Filter** — show only goals that use the data sources you pick. **Clear all** removes them.
- **Sort** — **Newest**, **Oldest**, **Name A-Z** or **Name Z-A**.

Your search, filter and sort stay while the report is open.
