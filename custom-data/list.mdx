The **Manage Custom Data** slide-over lists every dataset you've uploaded — its name, row count, column count, file size, and upload date. Open it from the **Manage** button next to the **Dataset** label in a **Custom Data** widget.

## What's on a row

| Item | Description |
|---|---|
| Name | The name you gave the dataset when you saved it. |
| Columns | The columns read from the file's first row. |
| Rows | How many rows of data it has. |
| File size | The size of the uploaded file. |
| File name | The original file's name, if there was one. |
| Uploaded | When the dataset was first saved. |
| Last changed | When the dataset was last changed. |

## Quick actions

From the **Manage Custom Data** slide-over you can:

- **Edit** — change the data or rename the dataset. See [Update custom data](/custom-data/update).
- **Duplicate** — copy the dataset under a new name. See [Duplicate custom data](/custom-data/duplicate).
- **Archive** — archive the dataset; you can restore it later. See [Archive custom data](/custom-data/delete).

## API

`GET /v1/custom-data` returns a lightweight list of your datasets, newest first. The list response omits `raw_data` because it can be large — fetch a single dataset with `GET /v1/custom-data/{id}` to include `raw_data`.
