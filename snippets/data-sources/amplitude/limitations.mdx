**Limits set by Amplitude**

- **5 requests at once.** Amplitude runs at most 5 requests at the same time per API key, and limits how much it does each hour; long date ranges use more. A report with many Amplitude widgets can show **Amplitude is busy right now**.
- **Days follow your project's time zone.** Amplitude dates every number in your Amplitude project's time zone.

Amplitude's pages: [Dashboard REST API](https://amplitude.com/docs/apis/analytics/dashboard-rest).
