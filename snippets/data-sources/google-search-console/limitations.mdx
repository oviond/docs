**Limits set by Google**

- **History is 16 months.** Google Search Console keeps 16 months of data. Older dates show no data.
- **The newest days come late.** Google adds search data a few days after it happens, so the last days of a date range are often empty at first.
- **Rare searches are hidden.** Queries that only a few dozen people searched over 2–3 months are never listed, to protect privacy. They still count in the totals. So a **Query** table can add up to less than the total clicks and impressions.
- **Splitting by page changes the totals.** Split by **Query**, **Country**, **Device** or date, Google counts the site as one: two results from your site on one search count as 1 impression. Split by **Page** or **Search Appearance**, each page counts on its own, so the same search can count as 2. So these widgets can show different totals for the same dates.
- **Big sites don't get every row.** Google gives at most 50,000 rows a day per site for each search type (web, image, video and so on), so very big sites can lose some rare pages or queries.
