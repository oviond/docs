**Limits set by Plausible**

- **A Business plan is needed.** On Plausible Cloud, the Stats API is a Business plan feature. Other plans can't connect.
- **One team per key.** A Plausible API key only sees the sites of its own team.
- **600 requests an hour.** Plausible allows 600 Stats API requests an hour by default. Each widget uses 1 request when it loads (2 with a comparison), so busy reports can show **Plausible is busy right now**.

Plausible's pages: [Stats API](https://plausible.io/docs/stats-api).
