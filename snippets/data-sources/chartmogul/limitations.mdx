**Limits set by ChartMogul**

- **Request limits.** ChartMogul allows 40 requests a second and also limits heavy reports per minute; past that, widgets show **ChartMogul is busy right now**. It also allows only 20 requests at the same time; past that, widgets show **ChartMogul isn't responding**. Each widget makes 3 requests when it loads (6 with a comparison).

ChartMogul's pages: [rate limits](https://dev.chartmogul.com/docs/rate-limits).
