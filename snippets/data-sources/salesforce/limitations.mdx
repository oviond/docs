**Limits set by Salesforce**

- **Newer orgs block this sign-in.** Oviond signs in with your username, password and security token (Salesforce's username-password flow). Since Salesforce's Winter '24 release, this flow is blocked by default in orgs created in Summer '23 or later. A Salesforce admin can allow it under **OAuth and OpenID Connect Settings** with **Allow OAuth Username-Password Flows**.
