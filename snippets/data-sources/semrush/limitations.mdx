**Limits set by Semrush**

These apply to connections made with an **API Key**.

- **A Business plan and API units are needed.** Semrush's API needs a Business subscription and a bought package of API units. When the units run out, widgets show an error until you buy more.
- **Each line of data costs units.** Semrush charges API units for every line it returns (for example 10 units per line for domain organic keywords).

Semrush's pages: [API units](https://developer.semrush.com/api/basics/api-units-balance/), [domain reports](https://developer.semrush.com/api/v3/analytics/domain-reports/), [get started](https://developer.semrush.com/api/basics/get-started/).
