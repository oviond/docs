**Limits set by Advanced Web Ranking**

- **The API needs a yearly plan or Agency and up.** Advanced Web Ranking's API is available on all yearly plans, and on monthly plans from Agency up. Smaller monthly plans can't connect.
- **150 ranking exports an hour.** Each Rankings widget asks Advanced Web Ranking for 1 ranking export when it loads (2 when it compares with an earlier period). Advanced Web Ranking allows 150 of these an hour, shared with its other export calls. Most other API calls are limited to 2,000 an hour.

Advanced Web Ranking's pages: [developer API](https://www.advancedwebranking.com/docs/developer-api-v2.html).
