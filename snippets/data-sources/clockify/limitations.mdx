**Limits set by Clockify**

- **Free workspaces get 30 requests an hour.** Clockify limits API keys by workspace plan: 30 requests an hour on Free, 20 a second on Basic, Standard and Pro, 50 a second on Enterprise. On a Free workspace, a few widget loads can use the hour's requests, and widgets show **Clockify is busy right now**.

Clockify's pages: [API docs (rate limits, regional servers)](https://docs.clockify.me/).
