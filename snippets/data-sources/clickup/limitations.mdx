**Limits set by ClickUp**

- **100 requests a minute on most plans.** ClickUp limits requests per minute for each token, by workspace plan: 100 on Free Forever, Unlimited and Business, 1,000 on Business Plus, 10,000 on Enterprise. ClickUp sends 100 tasks per request, so a big space or many ClickUp widgets can show **ClickUp is busy right now**.
- **Only tasks you can see.** Oviond sees the tasks the connected ClickUp user has access to.

ClickUp's pages: [rate limits](https://developer.clickup.com/docs/rate-limits), [filtered tasks](https://developer.clickup.com/reference/getfilteredteamtasks).
