**Limits set by Google**

- **Lighthouse is a test run right now.** Each **Lighthouse** widget runs a new test of your website when it loads. It has no history, so the widget's dates don't change it.
- **Lighthouse scores change from run to run.** Google's test server, its network and the page itself vary, so the same page can score a little higher or lower each time, even if nothing changed.
- **Chrome User Experience is the last 28 days.** Google gives real visitors' speed as one number for the last 28 days. It is updated once a day, around 04:00 UTC. The widget's dates don't change it.
- **Chrome User Experience is for the whole website.** The numbers are for your whole website (for example `https://example.com`), mixing all its pages.
- **Small or private websites have no Chrome User Experience data.** Google only has it for public websites with enough Chrome visitors. Without it, the widget shows **This Google Page Speed account or property wasn't found**.
- **Lab and real numbers can disagree.** Lighthouse is one simulated visit on one device. Chrome User Experience is real visitors on many devices and networks. So they can tell different stories.

Google's pages: [about PageSpeed Insights](https://developers.google.com/speed/docs/insights/v5/about), [Chrome UX Report API](https://developer.chrome.com/docs/crux/api).
