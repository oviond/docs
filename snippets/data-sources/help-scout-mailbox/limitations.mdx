**Limits set by Help Scout**

- **No API on the Free plan.** Help Scout's Free plan doesn't include API access, so Free accounts can't connect.
- **Requests per minute by plan.** Help Scout limits API calls per minute for the whole account: 200 on Standard, 400 on Plus, 800 on Pro. Many Help Scout widgets loading at once can show **Help Scout Mailbox is busy right now**.

Help Scout's pages: [rate limiting](https://developer.helpscout.com/mailbox-api/overview/rate-limiting/), [API plans](https://docs.helpscout.com/article/1140-mailbox-api).
