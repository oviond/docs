**Limits set by Microsoft**

- **Only the last 3 days.** Clarity's API only gives data for the last 24, 48 or 72 hours before the request. Older dates aren't available.
- **10 requests a day per project.** Clarity allows only 10 API requests per project each day. Each widget uses 1 request when it loads (2 when it compares with an earlier period), so a few widgets and refreshes can use up the day. Then widgets show **Microsoft Clarity is busy right now** until the next day.
- **Up to 1,000 rows.** Clarity sends at most 1,000 rows per request, with no next page.

Microsoft's pages: [Clarity data export API](https://learn.microsoft.com/en-us/clarity/setup-and-installation/clarity-data-export-api).
