**Limits set by Ahrefs**

- **Each widget uses your Ahrefs API units.** Oviond reads Ahrefs with your own account, so every request uses API units from your Ahrefs plan. A request costs at least 50 units, more for many rows. Ahrefs' **Rank Tracker** requests are free. Your workspace admin can set a limit for Oviond in Ahrefs.
- **A paid Ahrefs plan is needed.** Apps like Oviond can only read Ahrefs for accounts on a paid plan (Lite, Standard, Advanced or Enterprise).
- **60 requests a minute.** Ahrefs allows 60 requests a minute, and can turn some away when it is busy. Then a widget shows **Ahrefs is busy right now**.

Ahrefs' pages: [API limits and units](https://docs.ahrefs.com/docs/api/reference/limits-consumption), [rate limits](https://docs.ahrefs.com/docs/api/reference/introduction), [Ahrefs Connect](https://docs.ahrefs.com/docs/ahrefs-connect/introduction), [all backlinks](https://docs.ahrefs.com/api/reference/site-explorer/get-all-backlinks).
