**Limits set by Close**

- **Requests per second.** Close limits requests per API key and per organization (the organization gets 3 times the key's limit). A report with many Close widgets can show **Close CRM is busy right now**.
- **Very long lists fail.** Close has a maximum number of items an app can skip through in a list, and it differs per list. When a date range holds more leads or opportunities than that, Close answers with an error and the widget shows **These settings aren't supported by Close CRM**. Use a shorter date range.

Close's pages: [rate limits](https://developer.close.com/topics/rate-limits/), [pagination](https://developer.close.com/topics/pagination/).
