**Limits set by Kit**

- **Oviond uses Kit's older API (v3).** Kit has stopped developing this API, so new Kit features don't show in Oviond.
- **Lists come 50 at a time.** Kit sends subscribers and broadcasts in pages of 50, and broadcasts oldest first.

Kit's pages: [API v3 (deprecated)](https://developers.kit.com/api-reference/v3/overview), [subscribers](https://developers.kit.com/api-reference/v3/subscribers), [broadcasts](https://developers.kit.com/api-reference/v3/broadcasts).
