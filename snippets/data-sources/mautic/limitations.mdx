**Limits set by Mautic**

- **Basic authentication must be on.** Oviond signs in with your Mautic username and password (Basic authentication). Mautic only allows this when it is turned on under **Configuration > API Settings**. Without it, the connection fails.

Mautic's pages: [API authentication](https://devdocs.mautic.org/en/5.x/rest_api/authentication.html).
