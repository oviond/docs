**Limits set by Atlassian**

- **Requests are limited.** Jira Cloud limits how much work and how many requests per second it takes from each sign-in. Many Jira widgets on big projects can show **Jira is busy right now**.
- **Only issues you can see.** Oviond signs in with the Atlassian account email and API token you entered, so it only sees the issues that account can see.

Atlassian's pages: [Jira Cloud rate limiting](https://developer.atlassian.com/cloud/jira/platform/rate-limiting/).
