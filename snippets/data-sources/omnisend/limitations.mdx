**Limits set by Omnisend**

- **55 requests in 24 hours.** Omnisend allows its reports (Campaigns and Automations) and its statistics (Subscribers) only 10 requests a minute and 55 in 24 hours each, for each brand. Each widget uses 1 request when it loads, so a report with many Omnisend widgets, or many refreshes, can use them up. Then widgets show **Omnisend is busy right now**.
- **Campaigns and automations count by send date.** Omnisend groups campaign and automation numbers by the day each message was sent. **Subscribers** counts by the day things happened.

Omnisend's pages: [reports API](https://api-docs.omnisend.com/reference/post_analytics-reports), [statistics API](https://api-docs.omnisend.com/reference/post_analytics-statistics).
