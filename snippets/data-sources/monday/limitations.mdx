**Limits set by monday.com**

- **Daily API call limits by plan.** monday.com limits API calls per account each day (resets at midnight UTC): 200 on Free, 1,000 on Standard and Basic, 10,000 on Pro and trials, 25,000 on Enterprise. Each widget load makes at least one call per board in the workspace, so a big workspace can use up a small plan's calls. Then widgets show an error until the next day.
- **Heavy requests are limited per minute.** monday.com also limits how much work requests take each minute. Many monday.com widgets loading at once can show **Monday is busy right now**.

monday.com's pages: [rate limits](https://developer.monday.com/api-reference/docs/rate-limits).
