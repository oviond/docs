**Limits set by PayPal**

- **History is 3 years.** PayPal's transaction search only covers the previous 3 years. Older dates show no data.
- **New transactions can take 3 hours.** A transaction can take up to 3 hours to show up in PayPal's API.

PayPal's pages: [Transaction Search API](https://developer.paypal.com/api/transaction-search/v1/).
