**Limits set by SendGrid**

- **Subusers see only their own numbers.** A parent account sees its own totals; a subuser's API key only sees that subuser's emails.

SendGrid's pages: [global email statistics](https://www.twilio.com/docs/sendgrid/api-reference/stats/retrieve-global-email-statistics), [statistics overview](https://www.twilio.com/docs/sendgrid/ui/analytics-and-reporting/stats-overview).
