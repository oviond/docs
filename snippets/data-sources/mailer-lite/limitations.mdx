**Limits set by MailerLite**

- **MailerLite Classic accounts only.** Oviond uses MailerLite's Classic API, which only works for MailerLite Classic accounts (created before March 2022). Accounts created after that use MailerLite's new API, and their API keys can't connect.

MailerLite's pages: [Classic API](https://developers-classic.mailerlite.com/docs/getting-started-with-mailerlite-api).
