**Limits set by Google**

- **Request limits.** Google limits how often apps can read sheets: by default 60 reads a minute for each Google account. A report with many sheet widgets can show **Google Sheets is busy right now** for a minute.
- **Very big sheets can time out.** Google stops a read that takes longer than 180 seconds.

Google's pages: [Sheets API limits](https://developers.google.com/workspace/sheets/api/limits).
