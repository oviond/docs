**Limits set by X**

- **250 requests every 15 minutes.** X allows 250 stats requests every 15 minutes per user. X returns at most 7 days per request. A long date range, or many X Ads widgets, can show **X Ads is busy right now**.
- **Spend can still change.** Spend is usually final within 3 days, but X can adjust billing for up to 14 days (for example after spam filtering).
- **Splits don't always add up.** Numbers split by something (like device or location) are not expected to add up exactly to the total.
