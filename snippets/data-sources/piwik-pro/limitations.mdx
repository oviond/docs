**Limits set by Piwik PRO**

- **60 sign-ins a minute.** Piwik PRO allows 60 sign-in requests a minute for each API client and IP address. A report with many Piwik PRO widgets, or several reports at once, can show **Piwik PRO is busy right now**.

Piwik PRO's pages: [API getting started (sign-in limit)](https://developers.piwik.pro/en/latest/platform/getting_started.html), [reporting API](https://developers.piwik.pro/en/latest/custom_reports/http_api/http_api.html).
