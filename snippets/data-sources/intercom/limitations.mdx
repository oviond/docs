**Limits set by Intercom**

- **Request limits.** Intercom allows an app 10,000 API calls a minute, spread over 10-second windows, and 25,000 a minute for all apps in a workspace. Other apps in your workspace use the same workspace limit.

Intercom's pages: [rate limiting](https://developers.intercom.com/docs/references/rest-api/errors/rate-limiting).
