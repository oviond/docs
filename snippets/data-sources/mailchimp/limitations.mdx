**Limits set by Mailchimp**

- **Audience Activity covers 180 days.** Mailchimp only gives day-by-day audience activity for the last 180 days. Activity from automations isn't included.
- **Automations are classic automations only.** Mailchimp's API lists classic automations. Customer Journeys (the newer automation flows) aren't in the **Automations** view.
- **1,000 rows per request.** Mailchimp sends at most 1,000 items at a time.

Mailchimp's pages: [audience activity](https://mailchimp.com/developer/marketing/api/list-activity/list-recent-activity/), [automations](https://mailchimp.com/developer/marketing/api/automation/), [reports](https://mailchimp.com/developer/marketing/api/reports/).
