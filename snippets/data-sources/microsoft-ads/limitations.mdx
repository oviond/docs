**Limits set by Microsoft**

- **Reports are made on request.** Microsoft builds a report for each request. A big account or a long date range takes longer, and a report that fails shows an error on the widget.
- **Too many requests are slowed down.** Microsoft can turn away requests from very busy accounts for a short while. Then widgets show **Microsoft Ads is busy right now**.

Microsoft's pages: [reports](https://learn.microsoft.com/en-us/advertising/guides/reports), [throttling](https://learn.microsoft.com/en-us/advertising/guides/services-protocol).
