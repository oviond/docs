**Limits set by Serpstat**

- **Each row costs a credit.** Serpstat charges 1 API credit for every row it returns. Each widget load uses credits from your Serpstat plan. When they run out, widgets show an error.
- **Requests per second by plan.** Serpstat allows 5 requests a second on Standard, 10 on Advanced and 30 on Enterprise. Many Serpstat widgets loading at once can show **Serpstat is busy right now**.
