**Limits set by Help Scout**

- **Requests every 10 minutes.** The Docs API allows 2,000 requests every 10 minutes with 1 Docs site, 3,000 with 2, and 4,000 with 3 or more. Work in the Help Scout admin counts too. A big site or many widgets can show **Help Scout Docs is busy right now**.

Help Scout's pages: [Docs API](https://developer.helpscout.com/docs-api/).
