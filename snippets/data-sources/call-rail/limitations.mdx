**Limits set by CallRail**

- **1,000 requests an hour, 10,000 a day.** CallRail limits API requests per account. **Calls Data** and **Form Submissions Data** read 250 items per request, so big accounts with many widgets can reach the limit. Then widgets show **Call Rail is busy right now** until it resets.
- **History is 25 months.** CallRail keeps calls and forms for 25 months. A widget whose dates start earlier gets an error from CallRail.
- **Days follow your CallRail time zone.** CallRail dates calls and forms in the time zone set in your CallRail account.

CallRail's pages: [API reference (rate limits, time zones)](https://apidocs.callrail.com/).
