**Limits set by Basecamp**

- **Requests are limited.** Basecamp's first limit is about 50 requests every 10 seconds per IP address, and it changes with load. With no list picked, one widget can make up to 31 requests at once, so a report with several Basecamp widgets can show **Basecamp is busy right now**.

Basecamp's pages: [API overview (pagination and rate limits)](https://github.com/basecamp/bc3-api).
