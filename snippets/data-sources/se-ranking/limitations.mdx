**Limits set by SE Ranking**

- **5 requests a second.** SE Ranking lets each API key make at most 5 requests a second. A report with many SE Ranking widgets can show **SE Ranking is busy right now**. If the limit is passed again and again, SE Ranking blocks the key for 10 minutes, and longer each time after that.
- **Your plan decides what you can read.** Requests use your SE Ranking subscription's limits, like the same actions in SE Ranking itself. A view your plan doesn't include shows an error.

SE Ranking's pages: [Project API](https://seranking.com/api/project/getting-started/), [rate limits](https://seranking.com/api/rate-limits/).
