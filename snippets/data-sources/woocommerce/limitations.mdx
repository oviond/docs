**Limits set by WooCommerce**

- **The shop needs WooCommerce 3.5 or newer and WordPress 4.4 or newer.**
- **Pretty permalinks must be on.** In WordPress, **Settings > Permalinks** must not be **Plain**. With plain permalinks, WooCommerce's API doesn't work and the connection fails.
- **Security tools can block Oviond.** Some firewalls and security plugins (like ModSecurity) block WooCommerce's API. Then the connection fails until the shop allows it.

WooCommerce's pages: [REST API](https://woocommerce.github.io/woocommerce-rest-api-docs/).
