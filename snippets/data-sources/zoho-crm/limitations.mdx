**Limits set by Zoho**

- **Your data center must match.** Zoho keeps each account in one data center (US, EU, India, Australia, Canada or Japan). Each widget's **Data Center Region**, under **Show Advanced Settings**, must match yours, or no data loads. The default is **United States**.

Zoho's pages: [Zoho CRM API](https://www.zoho.com/crm/developer/docs/api/v2/).
