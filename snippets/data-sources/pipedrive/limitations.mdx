**Limits set by Pipedrive**

- **A daily API budget.** Pipedrive gives each company a daily budget of API "tokens", shared by all its users and apps. Each request uses some of it. When it runs out, requests are blocked until it resets, and widgets show **Pipedrive is busy right now**.

Pipedrive's pages: [rate limiting](https://pipedrive.readme.io/docs/core-api-concepts-rate-limiting).
