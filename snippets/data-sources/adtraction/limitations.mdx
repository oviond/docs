**Limits set by Adtraction**

- **About 30 calls a minute.** Adtraction allows 30 calls a minute on most endpoints and 10 on some. Each widget uses 1 call when it loads (2 when it compares with an earlier period), so many Adtraction widgets can show **Adtraction is busy right now**.

Adtraction's pages: [get started with the Adtraction API](https://help.adtraction.com/en/articles/1563159-get-started-with-the-adtraction-api).
