---
title: "Add files to Ask Oviond"
description: "Ask about a file, or build a report that copies it."
---

You can add files to a question in Ask Oviond. It reads them in full — every page, sheet, picture and slide — and answers from them.

## Add a file

Click **+** in the message bar and pick the kind of file, or drag files onto the chat. You can add up to **5 files** to one question.

| File | Types | Largest size |
|---|---|---|
| Image | PNG, JPG, WebP, GIF | 5 MB |
| PDF | `.pdf` | 20 MB |
| Spreadsheet | CSV, Excel (`.xlsx`, `.xls`) | 30 MB |
| Word | `.docx` | 30 MB |
| PowerPoint | `.pptx` | 30 MB |

Ask Oviond keeps the chat's newest 5 files in mind for every question that follows, so you can ask follow-ups like *"now chart the second sheet"*.

## Build a report from a file

Add an old report — a PDF, a PowerPoint deck or a screenshot — and ask, for example: *"Build this report for Acme."*

Ask Oviond makes a **new, live report** that copies the file one to one:

- Every heading becomes a title, and every piece of text a text widget with the same words.
- Every number, chart and table that a connected platform measures becomes a **data widget**, so next month it shows next month's numbers.
- Pictures become image widgets. The client's logo goes on the client, and the file's cover goes on the report's cover page.
- The layout follows the file, page by page and row by row.

When it's done, it tells you which data sources to connect. Until you connect them, those widgets show demo numbers.

<Tip>
A big report can take a few minutes. If it runs out of time, it says what it finished and what's left. Reply *"continue"* to finish.
</Tip>

## Privacy

Files are only used to answer your questions. Deleting a chat deletes its files too.
