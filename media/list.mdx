---

The **Media Library** modal lists your uploaded images in a paginated grid, most recent first. Open it from any image picker (an **Image** widget's source, a report cover, or a branding logo control), then use the **Library** tab.

## Browsing

- **Folders** — the list on the left shows **All files** and your folders. See [Folders](/media/folders).
- **Search** — the **Search media…** box matches by name, inside the open folder.
- **Pagination** — the grid shows a page of items at a time, with **Prev** and **Next** controls.

## What's on a tile

| Item | Description |
|---|---|
| Thumbnail | A preview of the image. |
| Name | The item's name — see [Rename media](/media/update). |
| Size | The file size. |
| Type | The kind of image, for example PNG or JPG. |

## Per-item actions

Each tile has a `⋯` menu with:

- **Crop** — open the cropper to adjust the image.
- **Move to folder** / **Remove from folder** — see [Folders](/media/folders).
- **Archive** — move the item to the Archive. See [Delete media](/media/delete).

To pick an image, select a tile (or double-click) and choose **Use selected**.

## API

`GET /v1/media` lists your media, newest first, in pages. Query parameters: `page`, `limit` (max 100), `search` (matches `name`), and `folder_id`. The response includes a `meta` object with `page`, `limit`, and `total`. Soft-deleted items (`is_deleted`) are excluded.
