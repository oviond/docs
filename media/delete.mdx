---
title: "Delete media"
description: "Archive a media item. You can restore it later."
---

Archiving a media item moves it to the Archive — nothing is deleted for good at this step. You can restore it later from **Settings → Archive**.

<Steps>
  <Step title="Open the Library tab">
    Open the **Media Library** modal from any image picker and stay on the **Library** tab.
  </Step>
  <Step title="Open the item's menu">
    Click the `⋯` menu on the tile.
  </Step>
  <Step title="Choose Archive">
    The item moves to the Archive and leaves the library grid.
  </Step>
</Steps>

<Note>
Archiving needs **Admin access** or **Client access**; **Read-only access** can't archive.
</Note>

## Restore an archived item

Archived media can be restored. Go to **Settings → Archive**, filter by **Media**, and restore the item to return it to the library.

## What references see

Anything that referenced the deleted item — a widget image, a report cover, or a branding logo — shows a broken image until you edit it and pick a different file.

## API

`DELETE /v1/media/{id}` soft-deletes a single item. It returns `404` if the item doesn't exist (or is already deleted) in your account.
