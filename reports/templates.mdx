---
title: "Use and Create Report Templates"
description: "Save time with Oviond report templates. Create reusable templates from existing projects and apply them when building new reports for clients."
---

Templates in Oviond are reusable report structures you can apply when creating new projects. A template captures the page layout and widget configuration from an existing report — without the underlying data — so you can spin up consistent, pre-structured reports for new clients in seconds instead of building from scratch each time.

## What is a template?

A template is a saved snapshot of a project's structure: its pages, widget types, widget positions, and settings. When you create a new project from a template, Oviond copies that structure into the new project. You then connect each widget to the appropriate data source for that client.

Templates do not store live data or client-specific integration credentials — only the layout and configuration.

## Browse available templates

<Steps>
  <Step title="Open the Templates library">
    Click **Templates** in the left sidebar. This shows all templates available to your account, including any you've created and any Oviond-provided starter templates.
  </Step>
  <Step title="Preview a template">
    Click a template card to open a preview. The preview shows the page structure and widget layout so you can decide if it fits your needs before applying it.
  </Step>
</Steps>

## Create a new report from a template

<Steps>
  <Step title="Start a new project">
    Click **+ New Project** from the **Reports** screen.
  </Step>
  <Step title="Name the project and assign a client">
    Enter a project name and select the client this report is for.
  </Step>
  <Step title="Choose a template">
    Select **Start from template**, then browse the template list and click the template you want to use.
  </Step>
  <Step title="Create the project">
    Click **Create**. Oviond creates the project with all the template's pages and widgets pre-populated.
  </Step>
  <Step title="Connect your data sources">
    Open each widget and update the **Integration** setting to connect it to the correct data source for this client. The widget structure is ready — you only need to point it at the right data.
  </Step>
  <Step title="Save the project">
    Click **Save** once you've configured your widgets.
  </Step>
</Steps>

<Tip>
  Alternatively, you can create a new project from a template directly from the **Templates** screen by clicking **Use template** on any template card.
</Tip>

## Create a template from an existing project

If you've built a report you want to reuse, you can save it as a template. Oviond copies all pages and widgets from the project into the new template.

<Steps>
  <Step title="Open the Reports screen">
    Navigate to **Reports** in the left sidebar and find the project you want to turn into a template.
  </Step>
  <Step title="Open the project menu">
    Click the three-dot menu next to the project name.
  </Step>
  <Step title="Select Save as template">
    Click **Save as template** (or **Create template from project**).
  </Step>
  <Step title="Name the template">
    Enter a name for the template. Choose a name that describes the report structure or use case, such as "Monthly Google Ads Report" or "Full-Funnel Dashboard".
  </Step>
  <Step title="Add an optional description">
    Enter a description to help you and your team understand what the template is designed for — for example, which integrations it expects or what reporting period it covers.
  </Step>
  <Step title="Save the template">
    Click **Save**. The template appears in your **Templates** library and is available when creating new projects.
  </Step>
</Steps>

<Note>
  Creating a template from a project does not modify the original project. The two are independent after the template is created.
</Note>

## Edit template settings

You can update a template's name and description at any time without affecting projects that were already created from it.

<Steps>
  <Step title="Open the Templates library">
    Click **Templates** in the left sidebar.
  </Step>
  <Step title="Open the template menu">
    Hover over the template card and click the three-dot menu.
  </Step>
  <Step title="Select Edit">
    Click **Edit** (or **Settings**).
  </Step>
  <Step title="Update the name or description">
    Edit the **Template name** and **Description** fields as needed.
  </Step>
  <Step title="Save your changes">
    Click **Save**.
  </Step>
</Steps>

<Note>
  Editing a template's name or description does not update any projects that were already built from it. Template edits only affect future projects created from the updated template.
</Note>

## Duplicate a template

Duplicating a template is useful when you want to create a variation of an existing template — for example, a version with different widget types for a different reporting style.

<Steps>
  <Step title="Open the Templates library">
    Click **Templates** in the left sidebar.
  </Step>
  <Step title="Open the template menu">
    Hover over the template card and click the three-dot menu.
  </Step>
  <Step title="Select Duplicate">
    Click **Duplicate**. Oviond creates a copy with "Copy of" prepended to the template name.
  </Step>
  <Step title="Rename the duplicate">
    Edit the duplicate template's settings to give it a distinct name before using it.
  </Step>
</Steps>

## Delete a template

<Warning>
  Deleting a template removes it from your library permanently. Projects already created from the template are not affected — they continue to exist and work normally. However, you will no longer be able to create new projects from the deleted template.
</Warning>

<Steps>
  <Step title="Open the Templates library">
    Click **Templates** in the left sidebar.
  </Step>
  <Step title="Open the template menu">
    Hover over the template card and click the three-dot menu.
  </Step>
  <Step title="Select Delete">
    Click **Delete**, then confirm when prompted.
  </Step>
</Steps>
