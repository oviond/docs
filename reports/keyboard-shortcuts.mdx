## Report editor

Press **?** in the editor to open the list at any time. On Windows use **Ctrl**; on a Mac use **⌘ Command**.

| Shortcut | What it does |
|---|---|
| Ctrl/⌘ + Z | Undo |
| Ctrl + Y (Windows) / ⌘ + Shift + Z (Mac) | Redo |
| Ctrl/⌘ + S | Save now |
| Ctrl/⌘ + A | Select all widgets |
| Ctrl/⌘ + click | Add a widget to the selection, or take it out |
| Ctrl/⌘ + D | Duplicate the selected widgets |
| Delete or Backspace | Delete the selected widgets |
| Arrow keys | Nudge the selected widgets 1 px (hold Shift for 10 px) — Free Canvas reports only |
| Alt / ⌥ Option (hold) | Measure distances to other widgets, without snapping — Free Canvas reports only |
| Esc | Clear the selection |
| ? | Show the keyboard shortcuts |

Shortcuts don't fire while you're typing in a text box.

## Quick search

Press **Ctrl/⌘ + K** anywhere in the app to open the quick search. Type to find a client or a report by name, or jump straight to a page: **Clients**, **Reports**, **Automations**, **Browse Templates**, **Settings**, **Users**, **API Keys**, **Domains**, **Email Addresses**, **Email Domains** and **Email Templates**. Use the arrow keys and Enter to open a result.
