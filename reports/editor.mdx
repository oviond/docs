Open a report or dashboard from the client's **Reports** tab. It opens to **View**; click **Edit** to change it.

## The header

| Button | What it does |
|---|---|
| ← back | **Back to all reports** for this client. |
| Report name | Click it (**Edit report name**) to rename the report in place. |
| Date picker | The report's date range and comparison. It saves straight away, in view or edit mode. See [Configure a widget](/widgets/configure#date-range) for the options. |
| **Refresh** | Fetches fresh data for every widget. |
| **View** / **Edit** | Switches between looking at the report and changing it. |
| **Share** | The link, email, PDF download and embed code. See [Share a report](/reports/share). |
| ⋮ **More actions** | **Duplicate**, **Save As Template**, **View Automations** and **Archive**. See [List reports](/reports/list#actions-from-the-report-header). |

## The sidebar

| Tab | What it's for |
|---|---|
| **Pages** | Multi-Page Reports only: add, rename, reorder and delete pages, the cover, table of contents and thank-you page, and page setup. See [Pages](/pages/add). |
| **Add Content** | Drag widgets onto the page. See [Add a widget](/widgets/add). |
| **Ask Oviond** | The AI chat, aware of this report and the widgets you selected. See [Ask Oviond](/ask-oviond/overview). |
| **Assets** | Your saved widgets. See [Assets](/widgets/assets). |
| **Calculated Metrics** | Custom KPIs from formulas. See [Calculated metrics](/calculated-metrics/overview). |
| **Goals** | Targets for metrics. See [Goals](/goals/overview). |
| **Custom Data** | Your own uploaded data. See [Custom data](/custom-data/upload). |
| **Data sources** | Connect this client's platforms. See [Connect](/data-sources/connect). |
| **Automations** | Scheduled emails of this report. See [Automations](/automations/add). |
| **Themes** | Colours, fonts and cover designs. See [Themes](/themes/apply). |
| **Version History** | Earlier versions, to preview or restore. See [Version history](/reports/version-history). |
| **Settings** | Name, description, logo source, auto refresh and section links. See [Update a report](/reports/update). |

Click a widget to open its own settings in the sidebar. See [Configure a widget](/widgets/configure).

<Tip>
Press **?** in the editor to see the [keyboard shortcuts](/reports/keyboard-shortcuts).
</Tip>
