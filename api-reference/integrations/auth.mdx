---
title: "POST /v1/integrations/auth — Complete OAuth"
description: "POST /v1/integrations/auth — Completes the OAuth flow for a marketing platform and saves the auth profile. Accepts the authorization code and redirect URI."
---

Completes the OAuth authorization flow after the user has granted consent. Pass the authorization code returned by the OAuth provider to persist the connection.

## Request

```bash
POST https://backend.oviond.com/v1/integrations/auth
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "platform": "google_ads",
  "code": "OAUTH_CODE_FROM_CALLBACK",
  "redirectUri": "https://app.oviond.com/integrations/callback"
}
```

<ParamField body="platform" type="string" required>
  The integration platform identifier.
</ParamField>

<ParamField body="code" type="string" required>
  The OAuth authorization code from the provider callback.
</ParamField>

<ParamField body="redirectUri" type="string" required>
  The redirect URI used in the original OAuth request.
</ParamField>

## Response

Returns the saved auth profile object.

```json
{
  "id": "auth_abc123",
  "platform": "google_ads",
  "name": "My Google Ads Account",
  "createdAt": "2024-03-01T10:00:00Z"
}
```
