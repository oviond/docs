---
title: "GET /v1/integrations — List Integrations"
description: "GET /v1/integrations — Returns all saved integration auth profiles in your account, including platform identifier, display name, and creation date."
---

Returns all integration auth profiles saved in your account.

## Request

```bash
GET https://backend.oviond.com/v1/integrations
Authorization: Bearer YOUR_API_KEY
```

## Response

```json
{
  "data": [
    {
      "id": "auth_abc123",
      "platform": "google_ads",
      "name": "Client Google Ads",
      "createdAt": "2024-01-10T08:00:00Z"
    },
    {
      "id": "auth_def456",
      "platform": "facebook_ads",
      "name": "Client Facebook",
      "createdAt": "2024-01-12T09:30:00Z"
    }
  ]
}
```
