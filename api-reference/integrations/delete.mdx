---
title: "DELETE /v1/integrations/{id} — Delete Integration"
description: "DELETE /v1/integrations/{id} — Permanently removes an integration auth profile from Oviond, disconnecting it from all linked clients."
---

Permanently removes an integration auth profile. This disconnects the integration from all clients it was linked to.

## Request

```bash
DELETE https://backend.oviond.com/v1/integrations/{id}
Authorization: Bearer YOUR_API_KEY
```

<ParamField path="id" type="string" required>
  The integration auth profile ID to delete.
</ParamField>

## Response

Returns `204 No Content` on success.

<Warning>
  Deleting an integration removes it from all clients it was linked to. Widgets using this integration will stop showing data.
</Warning>
