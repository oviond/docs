---
title: "POST /v1/auth/verify — Complete Email Verification"
description: "POST /v1/auth/verify — Completes Oviond account creation after email verification. Accepts the token from the verification email plus account details."
---

Completes account creation after the user clicks the verification link in their email. First call `GET /v1/auth/verify/{token}` to validate the token and retrieve the email, then submit this endpoint to create the account.

## Validate token

```bash
GET https://backend.oviond.com/v1/auth/verify/{token}
```

Returns the associated email address if the token is valid.

## Create account

```bash
POST https://backend.oviond.com/v1/auth/verify
Content-Type: application/json

{
  "token": "VERIFICATION_TOKEN",
  "name": "Your Name",
  "password": "securepassword"
}
```

<ParamField body="token" type="string" required>
  The verification token from the email link.
</ParamField>

<ParamField body="name" type="string" required>
  The user's full name.
</ParamField>

<ParamField body="password" type="string" required>
  The account password (minimum 8 characters).
</ParamField>

## Response

Returns `200 OK` with a JWT access token on success.

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "usr_abc123",
    "email": "you@youragency.com",
    "name": "Your Name"
  }
}
```
