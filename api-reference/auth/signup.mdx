---
title: "POST /v1/auth/signup — Initiate Registration"
description: "POST /v1/auth/signup — Initiates the Oviond signup flow by sending a verification email. Accepts the user's email address and a CAPTCHA verification token."
---

Initiates the Oviond account signup flow by sending a verification email to the provided address. This endpoint is unauthenticated.

## Request

```bash
POST https://backend.oviond.com/v1/auth/signup
Content-Type: application/json

{
  "email": "you@youragency.com",
  "turnstileToken": "CAPTCHA_TOKEN"
}
```

<ParamField body="email" type="string" required>
  The email address to register.
</ParamField>

<ParamField body="turnstileToken" type="string" required>
  Cloudflare Turnstile CAPTCHA token from the signup form.
</ParamField>

## Response

Returns `200 OK` with a confirmation message. A verification email is sent to the provided address.

```json
{ "message": "Verification email sent." }
```
