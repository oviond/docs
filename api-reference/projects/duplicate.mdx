---
title: "POST /v1/projects/{id}/duplicate — Duplicate Project"
description: "POST /v1/projects/{id}/duplicate — Deep-copies an Oviond project including all pages and widgets. Optionally supply a custom name for the new project."
---

Creates a deep copy of a project, including all pages and widgets.

## Request

```bash
POST https://backend.oviond.com/v1/projects/{id}/duplicate
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "name": "Copy of Q1 Report"
}
```

<ParamField path="id" type="string" required>
  The ID of the project to duplicate.
</ParamField>

<ParamField body="name" type="string">
  Name for the duplicated project. Defaults to "Copy of [original name]".
</ParamField>

## Response

Returns `201 Created` with the new project object.

```json
{
  "id": "proj_copy123",
  "name": "Copy of Q1 Report",
  "clientId": "client_xyz789",
  "createdAt": "2024-03-10T11:00:00Z"
}
```
