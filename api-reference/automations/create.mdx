---
title: "POST /v1/automations — Create Automation"
description: "POST /v1/automations — Creates a new scheduled report automation in Oviond to deliver reports by email or PDF on a recurring schedule."
---

Creates a new scheduled report automation.

## Request

```bash
POST https://backend.oviond.com/v1/automations
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "name": "Weekly Performance Report",
  "projectId": "proj_xyz789",
  "schedule": "0 8 * * 1",
  "timezone": "America/New_York",
  "deliveryMethod": "email",
  "recipients": ["client@example.com"],
  "subject": "Your Weekly Report",
  "message": "Please find your weekly performance report below."
}
```

<ParamField body="name" type="string" required>
  Display name for the automation.
</ParamField>

<ParamField body="projectId" type="string" required>
  The project to deliver.
</ParamField>

<ParamField body="schedule" type="string" required>
  Cron expression defining the schedule (e.g., `0 8 * * 1` for every Monday at 8 AM).
</ParamField>

<ParamField body="timezone" type="string" required>
  IANA timezone name (e.g., `America/New_York`, `Europe/London`).
</ParamField>

<ParamField body="deliveryMethod" type="string" required>
  `email` or `pdf`.
</ParamField>

<ParamField body="recipients" type="array" required>
  Array of recipient email addresses.
</ParamField>

<ParamField body="subject" type="string">
  Email subject line.
</ParamField>

<ParamField body="message" type="string">
  Optional email body text.
</ParamField>

## Response

Returns `201 Created` with the new automation object.
