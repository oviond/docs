---
title: "Pause or Resume an Automation"
description: "PUT /v1/automations/{id}/pause or /unpause — Suspend or resume a scheduled Oviond automation without deleting it. Returns the updated status field on success."
---

Pauses or resumes a scheduled automation without deleting it. Use `/pause` to suspend and `/unpause` to resume.

## Pause

```bash
PUT https://backend.oviond.com/v1/automations/{id}/pause
Authorization: Bearer YOUR_API_KEY
```

## Unpause

```bash
PUT https://backend.oviond.com/v1/automations/{id}/unpause
Authorization: Bearer YOUR_API_KEY
```

<ParamField path="id" type="string" required>
  The automation ID.
</ParamField>

## Response

Returns `200 OK` with the updated automation object including the new `status` field (`paused` or `active`).

```json
{
  "id": "auto_abc123",
  "status": "paused"
}
```
