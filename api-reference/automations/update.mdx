---
title: "PUT /v1/automations/{id} — Update Automation"
description: "PUT /v1/automations/{id} — Updates an existing Oviond automation. Modify the cron schedule, timezone, delivery method, recipients, subject, or message body."
---

Updates an existing automation's settings.

## Request

```bash
PUT https://backend.oviond.com/v1/automations/{id}
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "schedule": "0 9 * * 5",
  "recipients": ["new-client@example.com"]
}
```

<ParamField path="id" type="string" required>
  The automation ID to update.
</ParamField>

All body fields from the [create endpoint](/api-reference/automations/create) are accepted and optional.

## Response

Returns `200 OK` with the updated automation object.
