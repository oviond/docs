---
title: "POST /v1/widgets — Create Widgets"
description: "POST /v1/widgets — Batch creates or upserts widgets on a report page in Oviond. Use to add charts, KPIs, and tables programmatically."
---

Batch creates or upserts widgets on a page. Send an array of widget objects to add or update them all in one request.

## Request

```bash
POST https://backend.oviond.com/v1/widgets
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "pageId": "page_abc123",
  "widgets": [
    {
      "type": "kpi",
      "metricId": "metric_impressions",
      "integrationId": "int_google_ads",
      "position": { "x": 0, "y": 0, "w": 3, "h": 2 }
    },
    {
      "type": "bar_chart",
      "metricId": "metric_clicks",
      "integrationId": "int_google_ads",
      "position": { "x": 3, "y": 0, "w": 9, "h": 4 }
    }
  ]
}
```

<ParamField body="pageId" type="string" required>
  The page to add widgets to.
</ParamField>

<ParamField body="widgets" type="array" required>
  Array of widget configuration objects.
</ParamField>

## Response

Returns `200 OK` with the created/updated widget IDs.
