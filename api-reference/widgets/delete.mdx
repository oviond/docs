---
title: "DELETE /v1/widgets — Delete Widgets"
description: "DELETE /v1/widgets — Bulk deletes one or more widgets from an Oviond report page. Pass an array of widget IDs to remove them all in a single request."
---

Bulk deletes one or more widgets by ID.

## Request

```bash
DELETE https://backend.oviond.com/v1/widgets
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "widgetIds": ["widget_abc", "widget_def"]
}
```

<ParamField body="widgetIds" type="array" required>
  Array of widget IDs to delete.
</ParamField>

## Response

Returns `204 No Content` on success.
