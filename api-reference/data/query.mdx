---
title: "POST /v1/data/query — Query Metrics"
description: "POST /v1/data/query — Queries live marketing metrics from a connected integration. Returns time-series or aggregate data for use in reports."
---

Queries live metrics from a connected integration. Use this endpoint to pull data for charts, KPIs, and tables in your reports.

## Request

```bash
POST https://backend.oviond.com/v1/data/query
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "integrationId": "auth_abc123",
  "datasourceId": "ds_campaign_xyz",
  "metrics": ["impressions", "clicks", "spend"],
  "dateRange": {
    "start": "2024-01-01",
    "end": "2024-01-31"
  },
  "granularity": "day"
}
```

<ParamField body="integrationId" type="string" required>
  The auth profile ID of the connected integration.
</ParamField>

<ParamField body="datasourceId" type="string" required>
  The specific account or campaign ID within the integration.
</ParamField>

<ParamField body="metrics" type="array" required>
  Array of metric names to retrieve.
</ParamField>

<ParamField body="dateRange" type="object" required>
  Object with `start` and `end` dates in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="granularity" type="string">
  Time grouping: `day`, `week`, `month`. Defaults to `day`.
</ParamField>

## Response

```json
{
  "data": [
    { "date": "2024-01-01", "impressions": 12400, "clicks": 340, "spend": 128.50 },
    { "date": "2024-01-02", "impressions": 11900, "clicks": 310, "spend": 121.00 }
  ]
}
```
