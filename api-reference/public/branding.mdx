---
title: "GET /v1/public/branding-by-domain"
description: "GET /v1/public/branding-by-domain — Returns white-label branding settings for an Oviond account by custom domain. Used to style shared report views."
---

Looks up white-label branding settings for a given custom domain. Used by client-facing report views to apply the correct agency branding when accessed via a custom domain.

## Request

```bash
GET https://backend.oviond.com/v1/public/branding-by-domain?domain=reports.youragency.com
```

<ParamField query="domain" type="string" required>
  The custom domain to look up (e.g., `reports.youragency.com`).
</ParamField>

## Response

```json
{
  "agencyName": "Your Agency",
  "logo": "https://youragency.com/logo.png",
  "primaryColor": "#3B82F6",
  "accentColor": "#F59E0B",
  "favicon": "https://youragency.com/favicon.ico"
}
```

Returns `404 Not Found` if no Oviond account has this domain configured.
