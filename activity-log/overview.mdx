title: "Activity log"

---

The **Activity log** records who did what and when across your account. Open it from **Settings → Activity log** (`/settings/activity-log`). Use it to:

- Trace when a client, report, or data source was created, updated, or deleted
- See which team member changed a role or removed a user
- Correlate a change with a recent data source action

## What each entry shows

The table has a row per action with these columns:

| Column | Description |
|---|---|
| **User** | The team member who did it, with their name and email. |
| **Action** | What happened, for example created, updated, deleted or restored. |
| **Type** | The kind of item, for example a client or a report. |
| **Source** | Where it came from: the app, the API, an AI app (MCP), or Oviond itself (system). |
| **Resource** | The name of the item (or `—`). |
| **Date** | When it happened, in your account timezone. |

## Filter and search

- **Search** by resource name or action.
- **Filter by type** — one type at a time: Client, Report, Page, Template, Theme, Asset, Goal, Calculated Metric, Saved Metric, Custom Data, Data Source, Automation, PDF, Export, Media, Folder, User, API Key, Custom Domain, Branding, Company, Email Provider or Email Sender.

<Note>
Over the API, a report's type is the stored value `project`. It's older than the rename to *report* and was kept so old log rows still match.
</Note>

## Who can see what

Admins see the whole account's activity. Other members see only their own actions.
