Themes live in the **Themes** panel inside the **report editor** — there's no standalone Themes page. Open any report, then open the **Themes** panel from the editor sidebar to see every theme on your account.

The list is a single, flat set of account-owned themes. Every account is seeded with starter themes you can use as-is or customise. Use the **search** box at the top of the panel to filter by name.

## What's on a theme row

| Element | Description |
|---|---|
| **Name** | Shown in the panel and in theme pickers. |
| **Colour swatches** | The theme's ten chart colours (`chart1`–`chart10`) as a preview strip. |
| **Default badge** | A **Default** star on your account's default theme, which sorts to the top. |
| **Active check** | A check mark on the theme currently applied to the open report. |

## Quick actions

Click a theme row to apply it to the open report. Hover a row for its actions (if you can manage shared assets):

- **Edit** — open the theme editor. See [Update Theme](/themes/update).
- **Duplicate** — copy the theme's full token set into a new theme.
- **Delete** — see [Delete Theme](/themes/delete).

<Note>
The **Default** theme is pre-selected for new reports that don't already get a theme from their client. Set the default with the **Set as default theme** toggle in the theme editor.
</Note>
