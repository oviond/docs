<Update label="2025-01-08" description="Instagram retires profile click metrics">

### Instagram retires profile click metrics

Meta removed the Instagram profile contact and click metrics on January 8, 2025. These metrics no longer return data. They are marked **Deprecated** in the widget editor.

- Email Contacts (`account_email_contacts`)
- Phone Call Clicks (`account_phone_call_clicks`)
- Text Message Clicks (`account_text_message_clicks`)
- Website Clicks (`account_website_clicks`)
- Get Directions Clicks (`account_get_directions_clicks`)

</Update>
