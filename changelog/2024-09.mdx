<Update label="2024-09-16" description="Facebook Pages retires more Page Insights metrics">

### Facebook Pages retires CTA clicks, negative feedback and check-in metrics

Meta removed another group of Page Insights metrics on September 16, 2024. These metrics no longer return data. They are marked **Deprecated** in the widget editor.

- Check-ins (`page_places_checkin_total`)
- Unique Check-ins (`page_places_checkin_total_unique`)
- Page Fans Online Per Day (`page_fans_online_per_day`)
- Total Page CTA Clicks (`page_cta_clicks_logged_in_total`)
- Unique Page CTA Clicks (`page_cta_clicks_logged_in_unique`)
- Website Clicks (`page_website_clicks_logged_in_unique`)
- Page Negative Feedback by Hide Post (`hide_clicks`)
- Page Negative Feedback by Hide All Posts (`hide_all_clicks`)
- Page Negative Feedback by Report as Spam (`report_spam_clicks`)
- Page Negative Feedback by Unlikes (`unlike_page_clicks`)
- Organic Page Impressions (`page_impressions_organic_v2`)
- Organic Impressions Of Posts (`page_posts_impressions_organic`)
- Organic Page Reach (`page_impressions_organic_unique_v2`)
- Negative Actions (`page_negative_feedback`)
- Unique Negative Actions (`page_negative_feedback_unique`)
- Unique Page Consumptions (`page_consumptions_unique`)
- Post Engaged Users by Page (`post_engaged_fan`)

</Update>
