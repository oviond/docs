<Update label="2025-11-15" description="Facebook Pages retires Page Likes and impressions">

### Facebook Pages retires Page Likes and impressions metrics

Meta removed Page Likes and the Page and post impressions metrics on November 15, 2025. These metrics no longer return data. They are marked **Deprecated** in the widget editor.

- Page Likes (`page_fans`)
- Unlikes (Unique Users) (`page_fan_removes_unique`)
- Total Impressions (`page_impressions`)
- Paid Impressions (`page_impressions_paid`)
- Viral Impressions (`page_impressions_viral`)
- Non-Viral Impressions (`page_impressions_nonviral`)
- Post Impressions (`post_impressions`)
- Post Paid Impressions (`post_impressions_paid`)
- Post Impressions by Page Fans (`post_impressions_fan`)
- Post Organic Impressions (`post_impressions_organic`)
- Post Impressions (Viral) (`post_impressions_viral`)
- Post Impressions (Non Viral) (`post_impressions_nonviral`)

</Update>

<Update label="2025-11-01" description="Ahrefs turns off API v2">

### Ahrefs turns off API v2

Ahrefs stopped its API v2 on November 1, 2025. The backlink metrics below came from it and no longer return data. They are marked **Deprecated** in the widget editor.

- Backlinks (`backlinks`)
- Referring Pages (`refpages`)
- Pages (`pages`)
- Valid Pages (`valid_pages`)
- Text (`text`)
- Image (`image`)
- NoFollow (`nofollow`)
- DoFollow (`dofollow`)
- Redirect (`redirect`)
- Canonical (`canonical`)
- Alternate (`alternate`)
- Governmental (`gov`)
- Educational (`edu`)
- RSS (`rss`)
- Html Pages (`html_pages`)
- Referring Domains (`refdomains`)
- Referring Class C (`refclass_c`)
- Referring IPs (`refips`)
- Linked Root Domains (`linked_root_domains`)

</Update>
