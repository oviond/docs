---
title: "Content types"
description: "The widget types you can add from the Add Content tab."
---

From the **Add Content** tab you can drag in any of these content types:

| Type | Use for |
|---|---|
| **Data Query** | A metric, chart, table, or KPI driven by a data source. Pick the chart type after the data is set. |
| **Heading** | A section title on the page. |
| **Textbox** | Freeform text — commentary, summaries, notes. |
| **Image** | An image from the Media Library or a URL. |
| **Button** | A call-to-action link (for example, to a booking page). |
| **Embed** | Any iframe-compatible source. |

<Tip>
**Data Query** is the only type that connects to a data source. The rest are presentation widgets you can use to frame and annotate your data.
</Tip>
