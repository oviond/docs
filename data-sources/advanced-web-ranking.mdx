  <Tab title="Overview">

    Keyword rank tracking and SERP analytics. Website: [advancedwebranking.com](https://www.advancedwebranking.com).

    **Connect**

    You connect Advanced Web Ranking with your **API Key**. Steps: [Connect a data source](/data-sources/connect).

    **Data views**

    A widget reads one data view: you pick it first, then its metrics and dimensions. Advanced Web Ranking has 1 data view:

    | Data view | ID | Metrics | Dimensions |
    |---|---|---|---|
    | Rankings | `RANKINGS` | 13 | 8 |

    Every metric and dimension, with its ID, format and summary, is in the **Metrics & dimensions** tab.

  </Tab>
  <Tab title="How it works">

    <Steps>
      <Step title="Connect Advanced Web Ranking">
        In the client's **Data sources**, open **Advanced Web Ranking**, name the connection and enter your **API Key**.
      </Step>
      <Step title="Pick the project">
        Choose the project to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **Advanced Web Ranking**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks Advanced Web Ranking for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    If the details stop working (for example a key is deleted), the connection shows **Needs attention**. Click **Edit connection details**, enter them again and click **Save and test**. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).

  </Tab>
