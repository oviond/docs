  <Tab title="How it works">

    <Steps>
      <Step title="Connect Surnex">
        In the client's **Data sources**, open **Surnex**, name the connection and enter your **Read Only API Key**.
      </Step>
      <Step title="Pick the project">
        Choose the project to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **Surnex**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks Surnex for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    If the details stop working (for example a key is deleted), the connection shows **Needs attention**. Click **Edit connection details**, enter them again and click **Save and test**. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).
