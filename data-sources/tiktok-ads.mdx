  <Tab title="Overview">

    Track TikTok Ads performance metrics. Website: [ads.tiktok.com](https://ads.tiktok.com).

    **Connect**

    You connect TikTok Ads by signing in on the platform's website and letting Oviond read your data. Steps: [Connect a data source](/data-sources/connect).

    **Data views**

    A widget reads one data view: you pick it first, then its metrics and dimensions. TikTok Ads has 10 data views:

  <Tab title="How it works">

    <Steps>
      <Step title="Connect TikTok Ads">
        In the client's **Data sources**, open **TikTok Ads** and sign in to your TikTok Ads account. Allow Oviond to read your data.
      </Step>
      <Step title="Pick the advertiser account">
        Choose the advertiser account to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **TikTok Ads**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks TikTok Ads for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    If the sign-in expires or access is removed, the connection shows **Needs attention**. Click **Refresh connection** and sign in again with the same account. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).

  </Tab>
  <Tab title="Limitations">

    **Limits in Oviond**

    Each field's own rules are in the **Metrics & dimensions** tab.

    - **Connect it in the app.** AI tools (the MCP server and Ask Oviond) can't connect TikTok Ads, because it needs a sign-in in a browser. Once it is connected, they can link and use it.
    - **Some metrics and dimensions can't be used together.** The widget editor only offers the ones that work together.
    - **Some data views have advanced settings.** Under **Show Advanced Settings** in the widget's data settings you can change more options. Some settings take one choice, some take several. Some views need a setting there before the widget shows data.

  </Tab>
