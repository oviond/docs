    Help Scout Docs knowledge base analytics — article views, popularity, and collection performance. Website: [helpscout.com](https://www.helpscout.com).

    **Connect**

    You connect Help Scout Docs with your **API Key**. Steps: [Connect a data source](/data-sources/connect).

    **Data views**

    A widget reads one data view: you pick it first, then its metrics and dimensions. Help Scout Docs has 2 data views:

    | Data view | ID | Metrics | Dimensions |
    |---|---|---|---|
    | Articles | `ARTICLES` | 2 | 3 |
    | Collections | `COLLECTIONS` | 2 | 2 |

    Every metric and dimension, with its ID, format and summary, is in the **Metrics & dimensions** tab.

  <Tab title="How it works">

    <Steps>
      <Step title="Connect Help Scout Docs">
        In the client's **Data sources**, open **Help Scout Docs**, name the connection and enter your **API Key**.
      </Step>
      <Step title="Pick the Docs site">
        Choose the Docs site to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **Help Scout Docs**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks Help Scout Docs for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    If the details stop working (for example a key is deleted), the connection shows **Needs attention**. Click **Edit connection details**, enter them again and click **Save and test**. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).
