  <Tab title="Overview">

    Search engine optimization and webmaster tools. Website: [bing.com/webmasters](https://www.bing.com/webmasters).

    **Connect**

    You connect Bing Webmaster Tools by signing in on the platform's website and letting Oviond read your data. Steps: [Connect a data source](/data-sources/connect).

    **Data views**

    A widget reads one data view: you pick it first, then its metrics and dimensions. Bing Webmaster Tools has 3 data views:

    | Data view | ID | Metrics | Dimensions |
    |---|---|---|---|
    | Traffic | `TRAFFIC` | 3 | 3 |
    | Queries | `QUERIES` | 5 | 4 |
    | Pages | `PAGES` | 5 | 4 |

    Every metric and dimension, with its ID, format and summary, is in the **Metrics & dimensions** tab.

  </Tab>
  <Tab title="How it works">

    <Steps>
      <Step title="Connect Bing Webmaster Tools">
        In the client's **Data sources**, open **Bing Webmaster Tools** and sign in to your Bing Webmaster Tools account. Allow Oviond to read your data.
      </Step>
      <Step title="Pick the site">
        Choose the site to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **Bing Webmaster Tools**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks Bing Webmaster Tools for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    Oviond renews the Bing Webmaster Tools sign-in by itself. If the sign-in expires or access is removed, the connection shows **Needs attention**. Click **Refresh connection** and sign in again with the same account. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).

  </Tab>
  <Tab title="Limitations">

    **Limits in Oviond**

    Each field's own rules are in the **Metrics & dimensions** tab.

    - **Connect it in the app.** AI tools (the MCP server and Ask Oviond) can't connect Bing Webmaster Tools, because it needs a sign-in in a browser. Once it is connected, they can link and use it.
    - **Some metrics and dimensions can't be used together.** The widget editor only offers the ones that work together.
