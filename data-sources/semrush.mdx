  <Tab title="How it works">

    <Steps>
      <Step title="Connect Semrush">
        In the client's **Data sources**, open **Semrush** and sign in to your Semrush account. Allow Oviond to read your data.
      </Step>
      <Step title="Pick the project">
        Choose the project to report on.
      </Step>
      <Step title="Use it in widgets">
        Add a data widget, pick **Semrush**, then a data view, metrics and dimensions. One connection can be linked to many clients.
      </Step>
    </Steps>

    **How the data arrives**

    Oviond asks Semrush for the numbers when a widget is added or changed, when you click **Refresh**, and on the report's automatic refresh. Nothing is copied ahead of time. PDFs print the data saved in the report.

    **When the connection stops working**

    Oviond renews the Semrush sign-in by itself. If the sign-in expires or access is removed, the connection shows **Needs attention**. Click **Refresh connection** and sign in again with the same account. Fixing it fixes every client that uses it. See [Test Connection](/data-sources/test).

  </Tab>
  <Tab title="Limitations">

    **Limits in Oviond**

    Each field's own rules are in the **Metrics & dimensions** tab.

    - **Connect it in the app.** AI tools (the MCP server and Ask Oviond) can't connect Semrush, because it needs a sign-in in a browser. Once it is connected, they can link and use it.
    - **Some metrics and dimensions can't be used together.** The widget editor only offers the ones that work together.
    - **Some data views have advanced settings.** Under **Show Advanced Settings** in the widget's data settings you can change more options. Some settings take one choice, some take several. Some views need a setting there before the widget shows data.
